<objective>
Create the sync module that orchestrates a single portfolio synchronization cycle: poll QuantConnect Cloud → run reconciliation → persist snapshot as atomic JSONL → emit alert on discrepancy. Also provide a CLI entrypoint for manual triggering.

Purpose: This is the backend data pipeline that feeds portfolio state from QC into a local JSONL file, which the dashboard data layer reads. The module is callable (not a daemon) — Phase 16's scheduler will invoke it on the NYSE market schedule.

Output: `marketpilot/sync.py` (sync orchestrator) + `marketpilot/__main__.py` (CLI)
</objective>

  <action>
Create `marketpilot/sync.py` with these components:

1. **`SyncRecord` frozen dataclass** — fields: `generation: int`, `source_timestamp: datetime`, `captured_at: datetime`, `sync_status: str` (literal "success" | "api_error" | "reconciliation_mismatch"), `reconciliation_clean: bool`, `portfolio: dict` (serialized snapshot — cash, equity, holdings list, unrealized_profit), `orders_count: int`, `fills_count: int`, `deployment_status: str`, `algorithm_status: str`, `error_detail: str | None`. Method `to_json_dict()` returns all fields with datetimes as ISO-8601 UTC strings (`.isoformat()`).

2. **`SyncResult` frozen dataclass** — fields: `status: str`, `generation: int | None = None`, `error: str | None = None`, `alert_emitted: bool = False`.

3. **`atomic_jsonl_append(path: Path, record: dict) -> None`** — per D-04: write full existing content + new line to a `tempfile.mkstemp()` temp file in same directory (prefix=".sync_", suffix=".tmp"), `os.fsync()`, then `os.replace()` over original. Handle cleanup in `finally` block. Creates parent directory with `mkdir(parents=True, exist_ok=True)`.

4. **`read_last_sync_record(path: Path) -> dict | None`** — returns None if file missing or empty. Seeks to end, reads last 4096 bytes, splits on newline, parses last non-empty line with `json.loads()`. Falls back to reading entire file if last line incomplete in chunk.

5. **`_next_generation(path: Path) -> int`** — reads last record via `read_last_sync_record`, returns `last["generation"] + 1` or `1` if None.

6. **`_exceeds_threshold(decision: ReconciliationDecision, snapshot: QuantConnectPaperSnapshot) -> bool`** — per D-18: returns True if any mismatch has `mismatch_type` in {ORDER_ID, ORDER_STATE, FILL_DATA}, OR if CASH/HOLDINGS mismatch and `abs(local_value - quantconnect_value) / snapshot.portfolio_equity > Decimal("0.01")`. Returns False if no mismatches.

7. **`_build_success_record(path: Path, snapshot: QuantConnectPaperSnapshot, decision: ReconciliationDecision) -> dict`** — builds SyncRecord with `sync_status="success"` (or `"reconciliation_mismatch"` if decision has mismatches), `reconciliation_clean=len(decision.mismatches)==0`, portfolio dict from snapshot fields (cash/equity as str for Decimal, holdings as list of dicts, unrealized_profit from performance), generation from `_next_generation()`, `source_timestamp=snapshot.captured_at`, `captured_at=datetime.now(timezone.utc)`.

8. **`_build_error_record(path: Path, exc: Exception) -> dict`** — builds SyncRecord with `sync_status="api_error"`, `error_detail=str(exc)`, empty portfolio, generation from `_next_generation()`, `source_timestamp=datetime.now(timezone.utc)`, `captured_at=datetime.now(timezone.utc)`.

9. **`sync_portfolio(*, project_id: int, deploy_id: str, jsonl_path: Path, client: QCApiClient | None = None) -> SyncResult`** — main orchestrator per D-06:
   - Assert `PAPER_TRADING_ONLY is True` (RuntimeError if not) per D-21
   - Instantiate QCApiClient if None passed
   - Call `client.read_live_algorithm(project_id=project_id, deploy_id=deploy_id)` — on `QCApiError`: persist error record, return SyncResult(status="api_error", error=str(exc))
   - Call `reconcile_quantconnect_state(snapshot=snapshot, correlation_id=f"sync-gen-{generation}")` with empty local_order_intents/local_lifecycle_events/local_audit_records
   - If `_exceeds_threshold(decision, snapshot)`: call `event_for_system_incident(correlation_id, {"alert_type": "SYNC_DISCREPANCY", "authoritative_source": "quantconnect", "mismatch_types": tuple(m.mismatch_type.value for m in decision.mismatches), "auto_correct": False}, severity="high")` — store event in result
   - Persist success record via `atomic_jsonl_append`
   - Return `SyncResult(status="success", generation=record["generation"], alert_emitted=bool(alert))`

Module-level: `_logger = logging.getLogger("marketpilot.sync")`, `DEFAULT_JSONL_PATH = Path("data/portfolio_sync.jsonl")`.

All imports use `from __future__ import annotations`. Follow frozen dataclass pattern from reconciliation.py. All timestamps use `datetime.now(timezone.utc)` — never naive datetimes (per SAFE-04/D-11).

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-01 | Tampering | JSONL file on disk | mitigate | Generation counter detects out-of-order or corrupted writes; atomic write prevents partial lines |
| T-14-02 | Information Disclosure | sync error logs | mitigate | QCApiClient already applies CredentialRedactionFilter; sync module logs only status, never credentials |
| T-14-03 | Denial of Service | Unbounded JSONL growth | accept | ~288KB/day at 5-min cadence; rotation deferred per CONTEXT.md |
| T-14-04 | Spoofing | PAPER_TRADING_ONLY bypass | mitigate | Runtime assertion at sync_portfolio entry; pre-commit hook rejects False |
| T-14-05 | Tampering | Malformed QC API response | mitigate | QCApiClient returns typed QuantConnectPaperSnapshot; json.dumps ensures valid output |
</threat_model>
