## Tasks

Planned files: `docs/testing.md`, `.planning/phases/16-production-scheduler/16-VERIFICATION.md`, `tests/test_production_scheduler_regression.py`

- Create Phase 16 UAT/verification checklists for scheduler startup, lock behavior, job graph failures, heartbeat, missed-run monitor, and no-local-computer operation.
- Run full regression during execution and document any external gates that remain pending.
- Do not mark Phase 16, Phase 16.1, Phase 16.2, or v1.1 complete from planning artifacts alone.
