# Phase 16 Plan 01: Scheduler Clock And NYSE/ET Guard

## Objective

Create the scheduler foundation for APScheduler configuration and deterministic NYSE/ET market-session eligibility without starting production execution during planning.

## Tasks

### Task 1: Add scheduler dependency and configuration boundary

Planned files: `pyproject.toml`, `marketpilot/scheduler_config.py`, `tests/test_scheduler_calendar.py`

- Add APScheduler as an explicit project dependency during execution.
- Define scheduler config values for timezone, scan cadence, catch-up policy, and safety mode.
- Keep imports lazy or isolated so existing tests that do not run the scheduler continue to pass.
- Require `PAPER_TRADING_ONLY` validation at scheduler startup.

### Task 2: Implement NYSE/ET market-session guard

Planned files: `marketpilot/scheduler_calendar.py`, `tests/test_scheduler_calendar.py`

- Implement a deterministic guard that answers whether a scheduled cycle may create paper-order intent.
- Use `America/New_York` semantics for regular session windows, DST transitions, weekends, holidays, early closes, and stale-data skip behavior.
- Keep the guard independent from APScheduler so it can be tested with fake clocks.
- Return typed eligibility results, including skip reasons for closed market, stale cycle, weekend, holiday, and early close.

## Success Criteria

- APScheduler can be configured for an ET-aware worker without breaking existing imports.
- Market-session eligibility is tested independently of real wall-clock time.
- DST and market-closed cases never create order-intent eligibility.
- All existing safety gates remain in place and no external verification is faked.
