Add to `marketpilot/qc_api.py` the `QCApiClient` class with these components:

**Module-level constants:**
- `_ALLOWED_ENDPOINTS: frozenset[str]` containing: "authenticate", "live/read", "live/list", "backtests/create", "backtests/read", "backtests/list", "projects/read"
- `_PAPER_GATED_ENDPOINTS: frozenset[str]` containing: "live/create", "live/update/stop", "live/update/liquidate"

**QCApiClient.__init__(self, config: QCApiConfig | None = None):**
- If config is None: read `QUANTCONNECT_USER_ID` and `QUANTCONNECT_API_TOKEN` from `os.environ.get()`
- If either is empty/missing: raise `QCAuthenticationError` with message "QUANTCONNECT_USER_ID and QUANTCONNECT_API_TOKEN environment variables are required but missing or empty." (per D-03)
- Store config in `self._config`
- Create `self._session = requests.Session()` with Content-Type application/json header
- Attach `CredentialRedactionFilter` to `logging.getLogger("marketpilot.qc_api")`
- Call `self._validate_credentials()` to fail fast (per D-04)

**QCApiClient._get_auth_headers(self) -> dict[str, str]:**
- Generate fresh timestamp `str(int(time()))`
- SHA-256 hash of `"{api_token}:{timestamp}"`
- Base64 encode `"{user_id}:{hashed_token}"`
- Return dict with `Authorization: Basic {encoded}` and `Timestamp: {timestamp}`
- Never cache these headers (Pitfall 1 from RESEARCH.md)

**QCApiClient._validate_credentials(self) -> None:**
- GET `{base_url}/authenticate` with auth headers
- On 401: raise QCAuthenticationError("Invalid QC credentials — authentication failed")
- On other errors: raise_for_status
- Check response JSON `success` field; if not True, raise QCAuthenticationError

**QCApiClient._validate_endpoint(self, endpoint: str) -> None:**
- If endpoint not in `_ALLOWED_ENDPOINTS | _PAPER_GATED_ENDPOINTS`: raise QCSafetyError(f"Endpoint '{endpoint}' is not in the safety allowlist")
- If endpoint in `_PAPER_GATED_ENDPOINTS`: assert `PAPER_TRADING_ONLY is True` or raise QCSafetyError("PAPER_TRADING_ONLY must be True for deployment endpoints")
- Per D-07: Defense-in-depth safety gate

**QCApiClient._make_request(self, endpoint: str, payload: dict | None = None) -> dict:**
- Call `_validate_endpoint(endpoint)` first (safety gate before any network I/O)
- Determine method: GET if endpoint == "authenticate" else POST
- Build URL: `{base_url}/{endpoint}`
- Get fresh auth headers via `_get_auth_headers()`
- Execute request via session
- Map response status codes to custom exceptions: 401→QCAuthenticationError, 429→QCRateLimitError, 500-599→QCServerError, 400-499→QCClientError
- Catch `requests.exceptions.ConnectionError` and `requests.exceptions.Timeout` → QCNetworkError
- Return `response.json()`
- Decorate with tenacity: `@retry(retry=retry_if_exception_type((QCRateLimitError, QCServerError, QCNetworkError)), wait=wait_exponential_jitter(initial=1, max=30, jitter=2), stop=stop_after_attempt(4), reraise=True)`

Per D-08 / SAFE-02: No live brokerage credential paths. The only env vars consumed are QUANTCONNECT_USER_ID and QUANTCONNECT_API_TOKEN (paper trading cloud API credentials). No field, parameter, or config key ever accepts a real brokerage account credential.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Process → QC API | HMAC auth headers cross network; credentials must never leak to logs |
| Caller → QCApiClient | Callers must not bypass safety gate via direct HTTP |
| Environment → QCApiClient | Env vars are the only credential source; no config file fallback |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-13-03 | Spoofing | HMAC auth headers | mitigate | Fresh timestamp per request; SHA-256 hash; never cache auth headers |
| T-13-04 | Tampering | PAPER_TRADING_ONLY bypass | mitigate | _validate_endpoint checks constant before every paper-gated request |
| T-13-05 | Information Disclosure | Credentials in logs | mitigate | CredentialRedactionFilter attached to module logger; exceptions store redacted data only |
| T-13-06 | Elevation of Privilege | Direct HTTP bypass | mitigate | _session and _base_url are private; meta-test will grep for raw QC URLs outside qc_api.py (Plan 04) |
| T-13-07 | Denial of Service | Rate limit exhaustion | mitigate | tenacity exponential backoff with jitter; max 4 attempts; conservative retry scope |
| T-13-08 | Information Disclosure | Exception response_body | mitigate | QCApiError.response_body stores only first 500 chars; redaction filter covers log output |
| T-13-SC | Tampering | pip install tenacity | mitigate | Package Legitimacy Audit passed; 40M+ weekly downloads; well-known maintainer |
</threat_model>
