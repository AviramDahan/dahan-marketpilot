**Test groups (organize with class or just flat functions per project convention):**

**API-01 — HMAC Authentication:**
- `test_hmac_auth_generates_authorization_and_timestamp_headers` — create QCApiConfig with fake creds, call _get_auth_headers, assert "Authorization" starts with "Basic ", assert "Timestamp" is a numeric string
- `test_missing_env_vars_raises_authentication_error` — patch os.environ to be empty, instantiate QCApiClient(config=None), expect QCAuthenticationError with message containing "QUANTCONNECT_USER_ID"
- `test_invalid_credentials_fail_at_startup` — mock session.get to return 401, expect QCAuthenticationError

**API-02 — Safety Gate:**
- `test_safety_gate_blocks_unknown_endpoint` — call _validate_endpoint("live/deploy"), expect QCSafetyError
- `test_safety_gate_allows_read_endpoints` — call _validate_endpoint("live/read"), no exception
- `test_safety_gate_blocks_paper_gated_when_constant_false` — monkeypatch PAPER_TRADING_ONLY to False in qc_api module, call _validate_endpoint("live/create"), expect QCSafetyError, restore constant
- `test_safety_gate_allows_paper_gated_when_constant_true` — normal case, "live/create" passes

**API-03 — Retry Logic:**
- `test_retry_on_429_rate_limit` — mock _make_request to raise QCRateLimitError twice then succeed, assert called 3 times (uses tenacity's retry)
- `test_no_retry_on_401_auth_error` — mock to raise QCAuthenticationError, assert called exactly once
- `test_no_retry_on_400_client_error` — mock to raise QCClientError, assert called exactly once
- `test_retry_on_network_error` — mock to raise QCNetworkError then succeed

**API-04 — Credential Redaction:**
- `test_credential_redaction_filter_masks_authorization_header` — create log record with "Authorization: Basic abc123def", apply filter, assert "abc123def" not in result, assert "***REDACTED***" in result
- `test_credential_redaction_filter_masks_api_token_env_var` — create log record with "QUANTCONNECT_API_TOKEN=secret123", apply filter, assert "secret123" not in result
- `test_exception_does_not_leak_credentials` — construct QCAuthenticationError, ensure the api_token value does not appear in str(exception)

**API-05 — Typed Wrappers:**
- `test_read_live_algorithm_returns_paper_snapshot` — mock _make_request to return live_read fixture JSON, call read_live_algorithm, assert result is QuantConnectPaperSnapshot, assert holdings tuple has correct length
- `test_read_live_orders_returns_tuple_of_orders` — mock _make_request to return orders fixture, assert result is tuple, each element is QuantConnectPaperOrder
- `test_create_live_algorithm_hardcodes_paper_brokerage` — mock _make_request, call create_live_algorithm, capture payload passed to _make_request, assert payload contains `"brokerage": {"id": "QuantConnectBrokerage"}`
- `test_create_backtest_returns_response_with_backtest_id` — mock _make_request, call create_backtest, assert "backtestId" in result

**SAFE-01 — PAPER_TRADING_ONLY Assertion:**
- `test_paper_trading_only_constant_is_true` — `from marketpilot.constants import PAPER_TRADING_ONLY; assert PAPER_TRADING_ONLY is True`

**SAFE-02 — No Live Brokerage Paths (Meta-Test):**
- `test_no_direct_quantconnect_urls_outside_qc_api` — grep/scan all .py files in `marketpilot/` (excluding qc_api.py) for "quantconnect.com/api"; assert no matches. This prevents Pitfall 4 (safety bypass via direct requests).
- `test_no_live_brokerage_credential_attributes` — inspect QCApiClient for any attribute containing "live_brokerage", "real_broker", etc.; assert none found
