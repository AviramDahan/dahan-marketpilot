Add these public methods to QCApiClient:

**read_live_algorithm(self, *, project_id: int, deploy_id: str) -> QuantConnectPaperSnapshot:**
- Calls `self._make_request("live/read", {"projectId": project_id, "deployId": deploy_id})`
- Parses response into `QuantConnectPaperSnapshot` frozen dataclass:
  - Maps `cash` from response portfolio cash value to Decimal
  - Maps `holdings` from response portfolio holdings to tuple of `QuantConnectHolding`
  - Maps `portfolio_equity` from response statistics
  - Sets `fixture_label` to deploy_id for traceability
  - Sets `captured_at` to datetime.now(timezone.utc)
- Uses `.get()` with defaults for non-critical fields (Pitfall 5 from RESEARCH.md)
- Logs warning if unexpected keys found in response

**read_live_orders(self, *, project_id: int, deploy_id: str) -> tuple[QuantConnectPaperOrder, ...]:**
- Calls `self._make_request("live/read", {"projectId": project_id, "deployId": deploy_id})` and extracts orders section
- Maps each order JSON object to `QuantConnectPaperOrder` dataclass
- Returns tuple (immutable) of orders
- Handles empty orders list gracefully (returns empty tuple)

**create_backtest(self, *, project_id: int, compile_id: str, backtest_name: str) -> dict:**
- Calls `self._make_request("backtests/create", {"projectId": project_id, "compileId": compile_id, "backtestName": backtest_name})`
- Returns the raw response dict with backtestId and status
- No safety gate needed (backtests don't trade real money)

**read_backtest(self, *, project_id: int, backtest_id: str) -> dict:**
- Calls `self._make_request("backtests/read", {"projectId": project_id, "backtestId": backtest_id})`
- Returns raw response dict with full backtest results
- No safety gate needed

Add import at top of module: `from marketpilot.quantconnect_paper import QuantConnectHolding, QuantConnectPaperOrder, QuantConnectPaperSnapshot, QuantConnectAlgorithmStatus`

Use `from decimal import Decimal` for cash/price parsing.
Use `from datetime import datetime, timezone` for captured_at timestamps.

Per D-11: QC is authoritative; these read methods return snapshot data for local audit mirrors only.
