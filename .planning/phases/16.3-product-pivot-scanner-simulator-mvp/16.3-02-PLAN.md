# Phase 16.3 Plan 02: Universe Builder and Deterministic Scanner Inputs

## Objective

Formalize a deterministic stock universe source for scanner MVP runs while reusing existing universe quality decisions.

## Tasks

### Task 1: Add universe source loader

Planned files: `marketpilot/universe_sources.py`, `config/simulation_universe.yaml`

- Support configurable static watchlists and deterministic fixture lists.
- Normalize symbols, remove duplicates, and preserve original source labels.
- Do not use random stock selection.
- Return accepted/rejected source records with reasons.

### Task 2: Reuse data-quality filters

Planned files: `marketpilot/universe.py`, `tests/test_universe_sources.py`

- Convert source rows into `UniverseCandidate`.
- Reuse `build_universe_snapshot`.
- Apply liquidity filters when price/volume/dollar-volume data exists.
- Fail closed when required data is malformed.

### Task 3: Add deterministic tests

Planned files: `tests/test_universe_sources.py`, `tests/test_universe.py`

- Test duplicate removal.
- Test symbol normalization.
- Test rejection reasons.
- Test fallback fixture universe.
- Test no random ordering.

## Verification

- `python -m pytest tests/test_universe.py tests/test_universe_sources.py -q`

## Success Criteria

- The scanner has deterministic inputs.
- Every accepted or rejected symbol is explainable.
- No QuantConnect or broker dependency is introduced.
