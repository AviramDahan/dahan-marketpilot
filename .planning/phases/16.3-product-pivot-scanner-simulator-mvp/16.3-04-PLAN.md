# Phase 16.3 Plan 04: Internal Paper Simulator Portfolio and Trade Lifecycle

## Objective

Implement the internal paper simulator that opens, updates, and closes simulated trades without QuantConnect or broker dependency.

## Tasks

### Task 1: Add simulator domain model

Planned files: `marketpilot/internal_paper_simulator.py`

- Define simulated portfolio, open position, closed trade, lifecycle event, and simulator result contracts.
- Require symbol, strategy, score/rank, risk decision, entry, stop, target, quantity, open time, and idempotency key.
- Clearly label every record as internal simulation.

### Task 2: Implement entry and lifecycle logic

Planned files: `marketpilot/internal_paper_simulator.py`, `tests/test_internal_paper_simulator.py`

- Open simulated entries from accepted risk decisions.
- Mark open positions to latest available price.
- Close by stop hit, target hit, explicit system close, or configured holding status.
- Calculate realized and unrealized P&L.
- Preserve cash/equity accounting and reject invalid state transitions.

### Task 3: Add restart-safe storage

Planned files: `marketpilot/simulation_storage.py`, `tests/test_simulation_storage.py`

- Store simulator events in append-only JSONL or existing shared-state compatible payloads.
- Rebuild current open/closed state deterministically.
- Deduplicate idempotency keys.
- Never write secrets or raw credentials.

## Verification

- `python -m pytest tests/test_internal_paper_simulator.py tests/test_simulation_storage.py tests/test_risk_contract.py tests/test_position_sizing.py -q`

## Success Criteria

- Simulator can open, update, and close internal paper trades.
- P&L and portfolio state are deterministic and auditable.
- No real order, QC order, broker, or dashboard control path exists.
