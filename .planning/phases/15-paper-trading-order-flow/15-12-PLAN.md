<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local smoke to QuantConnect Object Store | Writes one namespaced Paper-only probe signal. |
| Paper algorithm to QuantConnect order system | Only LEAN inside the Paper deployment may submit the paper order. |
| `/live/orders/read` to local evidence docs | Authoritative order/fill/rejection data is sanitized before documentation. |
| Operator environment to repository | Secrets remain outside repo files and committed artifacts. |

## STRIDE Threat Register

| Threat | Risk | Mitigation |
|--------|------|------------|
| Spoofing | Treating logs or local audit records as order authority. | Require `/live/orders/read` evidence for order/fill/rejection status. |
| Tampering | Writing Object Store keys outside the MarketPilot namespace. | Use existing namespace-limited smoke and paper-gated wrappers only. |
| Repudiation | Losing the stop/cleanup trail for a keep-running deployment. | Record deployment id, stop result, cleanup result, and timestamp in sanitized summary. |
| Information Disclosure | Leaking QC credentials or chat-provided secrets. | Record variable names and safe ids only; run secret scan before commit. |
| Denial of Service | Leaving temporary Paper deployments running unintentionally. | `--keep-running` requires explicit approval and this plan requires final stop/cleanup. |
| Elevation of Privilege | Adding a real-money/broker bypass path. | No broker REST calls, real-money config, dashboard order controls, or unsupported asset classes are allowed. |
</threat_model>
