<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| runtime to command builder | Side-effect-free OrderIntent evidence becomes a command payload. |
| local JSONL ledger | Idempotency and audit records persist to local files. |
| Phase 14 sync JSONL to submission gate | Latest sync record is trusted only after schema and freshness checks. |
| local sender to QCApiClient | Validated command payload leaves the local process. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-02-01 | Tampering | stale signal submission | mitigate | Enforce UTC TTL before command delivery and append skip audit records per D-04. |
| T-15-02-02 | Tampering | duplicate deploy or signal replay | mitigate | Deterministic ledger keys reject duplicates before API calls per D-05. |
| T-15-02-03 | Elevation of Privilege | command payload | mitigate | Send only `marketpilot_signal` payloads; no direct external order command fields per D-03 and D-06. |
| T-15-02-04 | Information Disclosure | audit and ledger payloads | mitigate | Sanitize with existing audit journal behavior and exclude credential-like keys per D-08. |
| T-15-02-05 | Denial of Service | corrupt JSONL ledger | mitigate | Fail closed on unreadable ledger/sync records and avoid command delivery until state is explicit. |
| T-15-02-SC | Tampering | package installs | accept | No package installation occurs; use existing stdlib and project modules per D-12. |
</threat_model>
