## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| QuantConnect Commands API to `on_command` | External command payload enters LEAN runtime. |
| LEAN receiver to paper order call | Validated command becomes a QuantConnect paper order. |
| LEAN order event to evidence | Runtime order-event object becomes local trace evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-03-01 | Tampering | command payload | mitigate | Strict command type, schema, timestamp, symbol, and quantity validation before order call. |
| T-15-03-02 | Tampering | stale command replay | mitigate | Reject expired commands inside LEAN even if local sender failed per D-04. |
| T-15-03-03 | Tampering | duplicate command replay | mitigate | Maintain in-algorithm seen idempotency keys and reject duplicates before `market_order` per D-05. |
| T-15-03-04 | Elevation of Privilege | LEAN order path | mitigate | Permit only tagged paper `market_order` from accepted MarketPilot signal commands; keep brokerage and real-money paths forbidden per D-01. |
| T-15-03-05 | Information Disclosure | debug/order-event evidence | mitigate | Record ids/statuses/tags only; no credentials, tokens, passwords, or secret-like fields per D-08. |
| T-15-03-SC | Tampering | package installs | accept | No package installation occurs; use existing code and Python stdlib per D-12. |
</threat_model>
