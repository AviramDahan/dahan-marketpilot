<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local smoke script to QuantConnect Cloud API | Writes one paper-only signal object and reads sanitized metadata/log/order evidence. |
| QuantConnect Object Store to live algorithm | Shared organization storage carries delivery intent but is not order/fill authority. |
| LEAN adapter to MarketPilot validation | Adapter turns Object Store payloads into the same validated paper command path. |
| Verification docs to future operators/AIs | Must distinguish object write, algorithm receipt, rejection/order, fill, and portfolio authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-08-01 | Spoofing | Object Store signal key | mitigate | Use namespaced keys, correlation ids, idempotency keys, and paper-only payload markers. |
| T-15-08-02 | Tampering | Shared Object Store | mitigate | Restrict writes/deletes to a MarketPilot probe namespace and preserve sanitized evidence before cleanup. |
| T-15-08-03 | Repudiation | External smoke evidence | mitigate | Record object key, deploy id, correlation id, timestamps, receipt marker, order/rejection result, and cleanup status. |
| T-15-08-04 | Information Disclosure | Smoke output/logs | mitigate | Redact credentials, auth headers, secret-like values, and raw payloads from logs and docs. |
| T-15-08-05 | Denial of Service | Object Store polling | mitigate | Poll at a bounded interval, use a single probe key, avoid broad prefix scans in live callbacks, and clean up only namespaced probe data. |
| T-15-08-06 | Elevation of Privilege | Fallback order path | mitigate | Reuse existing paper-only validation and forbid broker REST/order bypasses or real-money brokerage settings. |
| T-15-08-SC | Tampering | Dependencies | accept | No new package installation planned; use stdlib, existing client code, and pytest. |
</threat_model>
