## Wave 0 Checks

- The phase has a single audited purpose: close runtime integration gaps INT-01 through INT-05.
- The phase explicitly excludes new strategies, new scoring weights, real-money support, dashboard order controls, fake portfolio/backtest/Paper state, and profitability claims.
- The plan set covers all phase requirement IDs plus audit-linked IDs called out by the plan checker: `QC-MTF-01`, `QC-MTF-02`, `SET-MTF-01`, `SET-MTF-02`, `SET-MTF-03`, `REG-04`, `TEL-04`, and `TEL-06`.
- Each plan has task-local `<done>` criteria and deterministic verification commands.
- External QuantConnect, Render, and Telegram checks remain `not_run` unless real operator-managed execution occurs.

## Validation Outcome Expected After Execution

The phase is Nyquist-compliant if execution proves all of the following:

- INT-01: deterministic runtime pipeline connects setup evidence, scoring, ranking, risk, order-intent evidence, notifications, and dashboard export.
