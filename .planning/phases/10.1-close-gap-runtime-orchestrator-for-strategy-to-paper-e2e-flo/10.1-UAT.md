# Phase 10.1 User Acceptance Test

SIMULATED PAPER TRADING ONLY - NOT FINANCIAL ADVICE

## Audit Finding Closure

This UAT maps each milestone audit integration finding (INT-01..INT-05) to
Phase 10.1 implementation evidence.

### INT-01: No production orchestrator wires strategy pipeline end-to-end

**Finding:** No production orchestrator wires QuantConnect universe/data through
setup evaluation, scoring/ranking, risk, order lifecycle, paper reconciliation,
Telegram, and dashboard.

**Evidence:**
- `marketpilot/runtime_orchestrator.py` implements `run_runtime_pipeline()` that
  composes setup → scoring → ranking → risk → order intents in a single pure
  function.
- Pipeline result includes `RuntimeOrchestrationStatus` (NOT_CONFIGURED,
  NOT_READY, BLOCKED, SHADOW_ONLY, PAPER_INTENT_READY).
- Reconciliation gate blocks new entries when QuantConnect snapshot mismatches.
- Notification-domain events are emitted from pipeline outcomes.
- Tests: `tests/test_runtime_orchestrator.py` (20 tests).

**Status:** Closed locally. External QuantConnect Cloud execution remains `not_run`.

### INT-02: lean/main.py does not import MarketPilot modules

**Finding:** `lean/main.py` remains a minimal benchmark shell and does not
import or call MarketPilot universe, indicator, setup, MTF, scoring, risk,
paper, or Telegram modules.

**Evidence:**
- `marketpilot/lean_runtime_bridge.py` defines the static safety policy and
  bridge contract for LEAN → runtime orchestrator integration.
- `tests/test_lean_runtime_bridge_static.py` proves the bridge cannot submit
  orders, call external APIs, or mutate portfolio state independently.
- The bridge is a contract layer; actual LEAN integration requires
  operator-approved QuantConnect deployment.
- Tests: `tests/test_lean_runtime_bridge_static.py` (8 tests).

**Status:** Closed locally (contract + static safety). LEAN runtime deployment
remains `not_run` pending operator approval.

### INT-03: Dashboard supports none/local_json but no Object Store source

**Finding:** Dashboard runtime loader supports `none` and `local_json` but no
QuantConnect Object Store/API producer or fetcher exists.

**Evidence:**
- `marketpilot/dashboard_export.py` implements `DashboardExportPayload`,
  `build_dashboard_export_payload()`, `FakeObjectStoreWriter`, and
  `ObjectStoreSourceLoader`.
- `dashboard/config.py` validates `object_store` as a valid data source kind.
- `dashboard/data.py` loads Object Store snapshots via `_load_object_store_snapshot()`.
- Tests: `tests/test_dashboard_object_store_source.py` (7 tests).

**Status:** Closed locally. Object Store write to real QuantConnect remains
`not_run` pending deployment.

### INT-04: Telegram signal/order alert emission from runtime pipeline (PARTIAL)

**Finding:** Telegram signal/order alert emission from runtime pipeline is
partial.

**Evidence:**
- `marketpilot/notification_events.py` provides typed event factories
  (`event_for_risk_rejection`, `event_for_sizing_decision`,
  `event_for_order_intent`, `event_for_system_incident`, `event_for_alert_family`).
- `marketpilot/runtime_orchestrator.py` emits notification events from pipeline
  outcomes with `controls_safety_logic=False` and
  `delivery_required_for_safety=False`.
- `marketpilot/telegram.py` delivers events via Telegram API with failure
  isolation (disabled, missing token, missing chat ID, HTTP failure, rate
  limited, duplicate suppressed — none alter safety).
- Tests: `tests/test_runtime_notification_emission.py` (13 tests),
  `tests/test_telegram_failure_isolation.py` (5 tests),
  `tests/test_notification_events.py` (varies).

**Status:** Closed locally. Real Telegram delivery requires externally supplied
bot token and chat ID (currently `not_run`).

### INT-05: Strategy signal → paper reconciliation → dashboard flow (BROKEN)

**Finding:** Strategy signal → scoring/ranking → risk sizing → order lifecycle →
paper reconciliation → Telegram → dashboard flow is broken.

**Evidence:**
- `run_runtime_pipeline()` connects the full strategy signal path locally.
- Reconciliation gate (`tests/test_runtime_reconciliation_gate.py`) blocks
  entries on snapshot mismatch.
- Dashboard export (`marketpilot/dashboard_export.py`) can serialize pipeline
  output for Object Store consumption.
- The flow is fully wired locally but requires QuantConnect Paper deployment
  for real execution.

**Status:** Closed locally. End-to-end with real QuantConnect Paper Trading
remains `not_run` pending operator-approved deployment.
